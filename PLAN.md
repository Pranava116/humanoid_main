Joint table (`config/stack/robot.yaml`):

| joint | board | ch | sign | limits (deg) |
|---|---|---|---|---|
| L_shoulder_pitch | 0x40 | 1 | +1 | -90 … 90 |
| R_shoulder_pitch | 0x40 | 3 | +1 | -90 … 90 |
| L_arm_roll | 0x40 | 4 | +1 | -11.46 … 90 |
| R_arm_roll | 0x41 | 0 | +1 | -11.46 … 90 |
| R_hip_roll / pitch / knee / ankle_pitch / foot_roll | 0x40 | 6–10 | +1 | from servos.yaml |
| L_hip_roll / pitch / knee / ankle_pitch / foot_roll | 0x40 | 11–15 | +1 | from servos.yaml |

Signs start at +1 and are set by `tools/calibrate_signs.py`.

Mapping (one function, `robot/hal/mapping.py`, used by every backend):
```
rel_deg   = sign * degrees(q_rad)                  # sim joint dir -> servo dir
rel_deg   = clamp(rel_deg, limits) and clamp(offset + rel_deg, -90, 90)
servo_deg = clamp(rel_deg + offset + 90, 0, 180)   # existing convention
```

## 3. Key interfaces

```python
# robot/hal/base.py
class ImuReading:  quat (w,x,y,z), rpy (rad), gyro (rad/s, body), accel (m/s², body), t
class Backend(ABC):
    joints: list[str]
    def set_joint_targets(self, targets: dict[str, float]) -> None   # rad, sim-convention
    def get_imu(self) -> ImuReading
    def get_camera_frame(self) -> np.ndarray | None                 # HxWx3 RGB
    def step(self, dt: float) -> None      # sim: advance physics; real/dry: no-op
    def release(self) -> None              # PWM off (real), zero kp (sim)
    def estop(self) -> None                # config: "release" or "hold"
    def close(self) -> None
def make_backend(name: str, cfg: Config, **opts) -> Backend
```
- **RealBackend**: ServoKit 0x40 on `ExtendedI2C(3)` exactly like `squat_at_center.py`. 0x41 probed at start and skipped with a warning if absent. MPU9250 on smbus2 (bus from config), gyro bias at boot, complementary filter. Camera = picamera2, falling back to OpenCV `VideoCapture`. Writes a channel only when it changed by more than the deadband.
- **SimBackend**: MuJoCo `scene.xml`, MG996R model, optional passive viewer, `realtime=True|False`, head-camera render.
- **DryBackend**: records every command in memory and logs it. Fake IMU, which tests can script, e.g. to make it "fall".

```python
# robot/hal/actuator_model.py — shared by SimBackend and RL (numpy; JAX twin in env_mjx.py with parity test)
class MG996R: step(cmd_rad, q, qd, dt) -> ctrl   # latency FIFO -> deadband -> backlash -> first-order lag -> speed clamp
```
MuJoCo `<position>` actuators provide kp and `forcerange=±1.08`.

```python
# robot/core
class ControlLoop(rate_hz=50, clock): register(callback); run(); stop()   # monotonic, overrun counter + warning
class Safety: filter(targets, dt) -> targets   # limits, max joint speed, estop latch, soft start ramp
class Telemetry: record(tick) ; ring buffer (N s) ; optional CSV ; snapshot() for dashboard
```
Every tick runs `commands -> FSM -> active behaviour -> targets -> Safety -> Backend -> Telemetry`.

```python
# robot/motion
Keyframe JSON: {"name", "joints": [...], "frames": [{"name","duration","hold","angles":{joint: deg}}], "loop": bool}
   angles in degrees relative to stand, joint names (not channels), sim convention (sign applied by HAL)
interp: smoothstep | minjerk ; Transition(from_pose, to_motion)
MotionPlayer: play(motion, blend_s), tick(dt) -> targets, done
walkgen.generate(step_len, step_h, lateral_shift, t_shift, t_step, n_steps) -> Keyframe   # 2-link IK, flat foot
importer: read-only conversion of the existing channel-keyed gait/squat JSON files
```

```python
# robot/behavior
Command(kind: str, args: dict, source: "voice"|"dashboard"|"teleop"|"auto")
   kinds: stand, sit, stop, walk(vx,vy,yaw), turn, wave(side), bow, raise_arms, come_here, follow, estop, reset
States: BOOT -> STAND -> IDLE <-> {WALKING, GESTURE, FOLLOW};  any -> FALLEN (fall detector);  any -> ESTOP
        FALLEN/ESTOP -> STAND only on explicit "reset"
FallDetector: tilt > θ for N ticks OR |gyro| > ω  -> stop, safe crouch, then release (configurable)
WalkingController: backend "keyframe" (walkgen + shuffle turns) or "rl" (PolicyRunner)
```

```python
# robot/rl/spec.py  (same code builds obs on the Pi and in training)
obs = [gravity_body(3), gyro(3), last N cmd targets (N*14), last action(14), cmd(vx,vy,yaw), sin/cos phase]
action = residual around stand | around keyframe reference;  scale, clip
reward terms + weights from rl.yaml; DR ranges from rl.yaml
```
`PolicyRunner` runs ONNX at 50 Hz through the HAL. `sim2sim.py` reports survival time and velocity-tracking error.

### Process layout
- **Pi (`python -m robot.run --backend real`)**: control loop, safety, FSM, HAL, plus a ZeroMQ link: PUB telemetry, PULL commands, PUB JPEG camera frames at low fps.
- **Pi or laptop**: `robot.interface.dashboard`, `robot.voice.client`, `robot.perception.client`. Each connects to the robot address from `network.yaml`. The same command objects flow through `robot/interface/bus.py`.
- **All in one process** (`--local`, used in sim and in tests): the same clients connect to an in-process queue instead of ZeroMQ.
- Perception sends `PersonObservation(bearing, size, conf, t)` back as a command-like message. The follow behaviour on the robot consumes it.

## 6. Honest risks

- **Timeline.** M1–M8 as code this week is feasible; *working on the real robot* is not guaranteed. A trained RL walker that transfers to open-loop MG996Rs in a week is unlikely. **The demo should use the keyframe gait; RL is the stretch goal.**
- **No encoders.** Soft start can't know where the servos are on boot. Like the existing scripts, it commands stand once (prompting you to support the robot) and then ramps. The safety speed limit acts on commands, not real motion.
- **Sim person detection.** A real person detector won't reliably fire on a simple MuJoCo shape. Sim uses `color_blob` by default; YOLO on the sim render is a config switch.
- **Turning by shuffle** with no hip yaw will be slow and slip-prone. It's tuned in sim, then on the robot.
- **Pi 4 load.** 50 Hz loop + detector + vosk on one Pi 4 is tight. The layout lets vision/voice move to the laptop.
